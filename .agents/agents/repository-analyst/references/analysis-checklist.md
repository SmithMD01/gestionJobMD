# Checklist de análisis de repositorio

## Estructura

- [ ] Identificar la raíz del proyecto.
- [ ] Revisar las carpetas principales.
- [ ] Identificar el punto de entrada.
- [ ] Identificar módulos importantes.

## Tecnologías

- [ ] Revisar package.json, requirements.txt u otros archivos equivalentes.
- [ ] Identificar framework principal.
- [ ] Identificar base de datos.
- [ ] Identificar servicios externos.

## Código

- [ ] Revisar rutas y vistas.
- [ ] Revisar componentes principales.
- [ ] Revisar servicios y APIs.
- [ ] Revisar modelos y acceso a datos.
- [ ] Identificar duplicaciones relevantes.

## Configuración

- [ ] Revisar comandos disponibles.
- [ ] Revisar archivos de configuración.
- [ ] Identificar variables de entorno sin exponer valores sensibles.
- [ ] Identificar comandos de desarrollo y pruebas.

## Entrega

- [ ] Indicar el alcance revisado.
- [ ] Separar hechos de inferencias.
- [ ] Registrar archivos utilizados como evidencia.
- [ ] Indicar dudas y limitaciones.
